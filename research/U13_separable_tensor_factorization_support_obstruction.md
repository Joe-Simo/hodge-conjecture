# U13: support obstruction for separable tensor products of two-variable Fermat factorizations

Status: verified obstruction for a restricted matrix-factorization ansatz only. This does not prove non-algebraicity of the target Hodge class and does not solve the Hodge conjecture.

Date: 2026-09-14.

## Target

Continue U07/U12 with

    Q = x0^70+x1^70+x2^70+x3^70+x4^70+x5^70

and target Fermat character

    alpha=(1,20,24,42,61,62) mod 70.

The corresponding Jacobian monomial is

    x1^19 x2^23 x3^41 x4^60 x5^61.

Test the first structured higher-rank matrix-factorization family: tensor products of three elementary two-variable factorizations, after a perfect matching of the six variables. This includes the standard separable/Koszul-type construction in which Q is split into three binary Fermat summands.

## Necessary character-support condition

For a two-variable Fermat factor `x_i^70+x_j^70`, an elementary equivariant factorization has character support in a binary sector whose diagonal Fermat character is trivial on the simultaneous scalar preserving the binary summand. On the middle Fermat character this forces the paired coordinates to be complementary modulo 70:

    a_i+a_j == 0 (mod 70).

A tensor product over three disjoint binary factors therefore requires a perfect matching of the six coordinates in which every matched pair has sum 0 modulo 70.

This is exactly the familiar support pattern of paired complete-intersection cycles, but here it is used as a rejection criterion for the entire separable tensor-product ansatz before any Favero-Kelly trace expansion.

## Exact exhaustive check

There are 15 perfect matchings of six indexed coordinates. Exact Wolfram enumeration computed the three pair sums modulo 70 for every matching.

No matching has even one full set of three complementary pairs; in fact U06 already showed that none of the 15 individual coordinate pairs has sum 0 modulo 70.

Representative matching sums include

    {(1,20),(24,42),(61,62)} -> {21,66,53},
    {(1,61),(20,42),(24,62)} -> {62,62,16},
    {(1,62),(20,61),(24,42)} -> {63,11,66}.

The exact result is

    pairSumZeroMatchings -> {}.

## Consequence

No matrix factorization obtained purely as a tensor product of three independent elementary two-variable Fermat factorizations can have primitive Chern-character support on V(alpha).

Direct sums of such objects do not help: their Chern characters add, so the character support remains in the union of the same separable paired sectors.

Extensions between objects whose K_0 classes are sums of these factors also do not enlarge the Chern-character span, because Chern character is additive in K-theory. Thus merely taking cones/extensions/direct sums inside the triangulated subcategory generated by these separable binary tensor products cannot create the missing alpha coefficient.

This is stronger than checking one standard complete intersection, but its scope is still restricted. It does NOT rule out:

- elementary factors coupling three or more variables;
- nonseparable higher-rank matrix factorizations;
- equivariant objects not generated in K_0 by the binary tensor-product family;
- geometric cycles obtained through weighted Delsarte correspondences.

## Next route

The minimal genuinely new ansatz must introduce multi-variable coupling. The next bounded family to test is a `4+2` decomposition: one nontrivial four-variable matrix factorization tensored with one binary factor. Character support then needs only one complementary pair, so the present alpha immediately shows that *every* 4+2 ansatz with an elementary binary factor is also impossible, because alpha has no complementary coordinate pair at all.

Therefore the first potentially viable separable block structure is `3+3`, with both factors genuinely three-variable. The next computation should classify zero-sum/grade-compatible three-coordinate character blocks and compare them against all 10 partitions of alpha into two triples, without assuming that ordinary zero-sum triples are the only possible three-variable factorization support.
